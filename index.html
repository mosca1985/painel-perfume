🔔 Painel do Perfume Bot

Para o painel ler e salvar as configurações do robô, ele precisa de uma chave do GitHub. A chave fica guardada só neste navegador.

Como criar a chave (uma vez só)

  1. Abra github.com/settings/personal-access-tokens/new
  2. Token name: painel-perfume · Expiration: 1 ano (ou o máximo)
  3. Repository access: Only select repositories → alerta-perfume-bot
  4. Permissions → Repository permissions: Contents = Read and write · Actions = Read and write
  5. Clique em Generate token, copie e cole abaixo.

O que o robô busca

Só os itens marcados são buscados. A caixinha ao lado do nome da divisão marca ou desmarca todos dela.

Depois de salvar, toque em ▶ Rodar agora para buscar na hora — senão vale a partir da próxima rodada automática.
